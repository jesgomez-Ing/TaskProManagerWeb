# Módulo de Gestión de Tareas

## Objetivo

Permitir registrar, consultar, modificar y eliminar tareas dentro de TaskPro Manager.

## Campos

* Título
* Descripción
* Prioridad
* Fecha de inicio
* Fecha de vencimiento
* Estado
* Responsable

## Funcionalidades

* Crear tarea
* Consultar tarea
* Editar tarea
* Eliminar tarea
* Filtrar tareas por estado
* Filtrar tareas por prioridad

## Caso de Uso Principal

El coordinador registra una nueva tarea y la asigna a un técnico para su ejecución y seguimiento.
