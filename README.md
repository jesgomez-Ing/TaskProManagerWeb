# TaskPro Manager

## Descripción

TaskPro Manager es una aplicación para la gestión y seguimiento de tareas internas en equipos técnicos. Permite registrar, asignar, monitorear y controlar tareas, facilitando la organización del trabajo y el seguimiento de actividades mediante módulos de usuarios, tareas, agenda, historial, notas, alertas y reportes.

## Objetivo

Automatizar el control, seguimiento y asignación de tareas técnicas dentro de un equipo de trabajo, mejorando la productividad y la trazabilidad de las actividades.
